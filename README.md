### Featured Projects

#### [Zestimator (Dubimator)](https://dubimator.vercel.app/) - Dubai Real Estate ML Platform
An end-to-end ML platform built on Dubai Land Department (DLD) transaction data, shipped across 11 phases:

| Phase | What it does |
|---|---|
| Ingestion | Cleans and structures raw DLD transaction data |
| Price Model | Predicts fair market value for listings |
| Fraud Detection | Flags duplicate & suspicious listings |
| Search Ranking | Ranks listings by relevance |
| Forecasting | Projects future price trends |
| FastAPI + Streamlit | Serves the models via API and an interactive demo |
| CI/CD + Monitoring | Automated deploys with production monitoring |

Runs locally on Docker + RTX 3060, tunneled live via Cloudflare, with an architecture overview deployed on Vercel.
[Live Demo & Architecture](https://dubimator.vercel.app/)

#### [Traceline](https://github.com/chiragn28/traceline_project) - Data Lineage & Compliance for MENA Fintech
A data governance and lineage/audit-trail tool aimed at compliant data pipelines for UAE/GCC fintech and trading firms - evolved from an earlier idea for a generic drag-and-drop pipeline builder into a focused compliance wedge, drawing on hands-on data engineering experience in quant/trading environments.

[Live Demo](https://traceline-pi.vercel.app/) - [Source](https://github.com/chiragn28/traceline_project)
